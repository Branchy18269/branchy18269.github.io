# Will Hyndman's Personal IT Portfolio
This repository contains the source code for my personal IT portfolio website. The site is designed to showcase my skills, professional experience, and education as I pursue a career in IT Systems Management and Security.The live version can be viewed at willhyndman.ca.✨ Features Modern & Responsive Design: A clean, dark-themed interface that looks great on all devices, from mobile phones to desktops.Dynamic Sections: Includes key sections like :About Me: A professional summary of my skills and career goals. Experience & Education: An interactive timeline detailing my work history and academic achievements. Skills Overview: A quick-glance grid of my core technical competencies.Contact Form: A functional form to get in touch. Interactive Elements: Subtle animations and a custom message system provide a polished user experience. Social & Professional Links: Easy access to my LinkedIn, GitHub, and other relevant profiles.🛠️ Tech Stack This website was built using a combination of modern front-end technologies :HTML5: For the core structure and content of the site. Tailwind CSS: For a utility-first approach to styling, enabling a rapid and responsive design process. JavaScript: For interactive elements like the mobile navigation menu and the contact form feedback. Font Awesome: For high-quality, scalable icons for social media and professional links. Google Fonts: Used for clean, professional typography (Inter font family).🚀 Getting StartedThis is a static website, so there is no complex build process required.
